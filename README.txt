Card Studio Pro testing PWA — built from saved Phase 3.5.3 complete editor (not basic one-card demo).
Open index.html to preview. Install/update needs HTTPS: upload all folder contents to root of a GitHub Pages repository and enable Pages in Settings.
For each new release, replace index.html and bump VERSION in sw.js; publish. Refresh/reopen and use Check for updates.
Existing editor save/export code is preserved; this release has not been browser regression-tested. Do not treat it as production stable.
The README for Phase 3.5.4 names a newer file, but it was not found in accessible saved files, so this is based on the latest retrieved Phase 3.5.3.
